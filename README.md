# Mario Platformer

Платформер на JavaScript с тремя уровнями и боссом.

## Управление

- **Стрелки** — движение и прыжок
- **Пробел** — прыжок
- **R** — рестарт
- **1/2/3** — выбор уровня в меню

## Уровни

1. **Forest Plains** — лёгкий уровень для старта
2. **Cave Ruins** — сложные платформы
3. **Dark Fortress** — битва с боссом и двумя стражами

## Особенности

- Босс неуязвим, пока живы оба стража рядом с ним
- После убийства стражей босс становится уязвим и умирает с одного прыжка
- Платформы выделены кирпичной текстурой
- Декоративные элементы (растения) на платформах
- Полноэкранный режим в браузере
